# 내용 기준

수학 내용의 기준 문서입니다. 페이지의 수식, 수치, 용어는 이 문서와 일치해야 합니다.
내용을 바꾸는 것은 Claude가 하고, 바꾼 뒤 `docs/HANDOFF.md`에 기록합니다.

## 프로젝트 목적

2022 개정 교육과정 **공통수학2**에서 출발해, 문제를 쉽게 풀게 해 주거나 꼭 필요한 아이디어를 고교 범위와 그 너머(교과외 공식, 대학 수학)까지 연결해 보여 줍니다. 각 노트는 직접 움직여 보며 확인하는 인터랙티브 페이지입니다.

## 다루는 범위

공통수학2 **Ⅰ. 도형의 방정식** 전체와 **Ⅱ-1. 집합**입니다.

| 중단원 | 성취기준 | 핵심 내용 | 교육과정상 제한 |
|---|---|---|---|
| 평면좌표 | 10공수2-01-01 | 두 점 사이 거리, 내분점 | 외분점 삭제 |
| 직선의 방정식 | 10공수2-01-02, 01-03 | 평행·수직 조건, 점과 직선 사이 거리 | 직선의 방정식 구하기 자체는 성취기준에서 빠짐 |
| 원의 방정식 | 10공수2-01-04, 01-05 | 원의 방정식, 원과 직선의 위치 관계 | 계산이 과도한 문제 제외 |
| 도형의 이동 | 10공수2-01-06, 01-07 | 평행이동, 대칭이동(원점·x축·y축·y=x) | 좌표축의 평행이동 제외 |
| 집합 | 10공수2-02-01 ~ 02-03 | 집합의 표현, 포함관계, 연산과 벤 다이어그램 | 연산 법칙은 벤 다이어그램으로 확인하는 정도 |

## 수준 표기

페이지와 문서에서 아이디어의 수준을 다음처럼 구분합니다.

| 표기 | 뜻 | 서술형 답안 |
|---|---|---|
| 공2 | 공통수학2 교과 범위 | 사용 가능 |
| 중·고 | 중학교 또는 다른 고교 과목 | 대체로 사용 가능 |
| 교과외 | 고교 수준이지만 교과서 밖 공식 (극선, 방멱, 신발끈 공식 등) | 인정되지 않을 수 있음 |
| 대학 | 대학·경시 수준 (반전, 라그랑주 승수, 불 대수 등) | 답 검증·출제 설계용 |

## 내용 원칙

- 모든 예제의 답과 공식은 코드로 검산한 뒤 싣습니다.
- 교과외·대학 아이디어는 가능하면 교과 풀이로 번역하는 방법을 함께 적습니다. (예: 반전 → SAS 닮음)
- 기출 문항을 언급할 때는 시험 연도·월·번호를 적고, 문항 자체를 옮겨 싣지 않습니다.

## 노트별 기준

### 반전 기하 실험실 (`inversion/`) · 공개

모든 그림의 반전원은 `x²+y²=4` (r=2)입니다.

| 섹션 | 내용 | 검산된 값 |
|---|---|---|
| 정의 | OP × OP′ = r² | 항상 4 |
| 성질 ① | △OAP ∽ △OP′A′, P′A′ = PA·r² ÷ (OA·OP), 반전원 = 아폴로니오스 원 | 두 식의 값이 항상 일치 |
| 성질 ② | a(x²+y²)+bx+cy+d=0 → d(X²+Y²)+r²bX+r²cY+r⁴a=0 | 반전 후 a = 원래 d, 반전 후 d = 16 × 원래 a |
| 성질 ② 주의 | 원(중심 C, 반지름 ρ, OC=d)의 상: 중심 r²C ÷ (d²−ρ²), 반지름 r²ρ ÷ \|d²−ρ²\| | 중심의 반전점과 다름 |
| 성질 ③ | 접함과 각 보존 | 반전된 두 원의 중심 거리 = 반지름의 합 또는 차 |
| 성질 ④ | 반전원과 직교하는 원은 제자리 | 중심 (3,0)일 때 ρ = √5 |
| 적용 A | P가 x=2 위, OP × OQ = 4 → Q의 자취 | (x−1)² + y² = 1, 원점 제외 |
| 적용 B 예제 1 | 원 위 P, A(1,0), B(−8,5), 2PA+PB | A′(4,0), 최솟값 13 |
| 적용 B 예제 2 | 원 위 P, A(4,0), B(1,5), PA/2+PB | A′(1,0), 최솟값 5, 등호점 (1, √3) |
| 적용 C | C₁: x²+y²=2x, C₂: x²+y²=4x 사이의 원 사슬 | 반전 후 x=2, x=1 / n번째 원 반지름 2 ÷ (n²+2), n=1이면 2/3 / 높이 = 2n × 반지름 |
| 톨레미 | AB·CD + AD·BC ≥ AC·BD | 네 점이 순서대로 한 원 위일 때 등호 |

## 후보 노트

아직 만들지 않은 노트입니다. 내용 정리가 끝나면 Claude가 `docs/HANDOFF.md`에 제작 요청을 올립니다.

### 라그랑주 승수법 · 내용 정리됨

- 핵심: 조건 g=c 위에서 f의 최대·최소는 f의 등고선이 조건 곡선에 접할 때. ∇f = λ∇g.
- 고교 대응: 원 위 일차식의 최대(직선을 움직여 접할 때), 점과 직선 거리(수선의 발), "중심을 지나는 직선 위에서 최대·최소".
- 검산된 예제
  - x²+y²=4 위에서 3x+4y의 최대 10, 최소 −10, 최대점 (6/5, 8/5)
  - 직선 x+2y=5 위에서 x²+y²의 최솟값 5, 점 (1, 2)
  - 원 (x−3)²+(y−4)²=1 위의 점과 원점 사이 거리 최소 4, 최대 6
  - λ의 의미: 원 x²+y²=c 위의 최댓값 5√c, c=4에서 변화율 5/4 = λ
- 주의: 필요조건일 뿐이며 서술형에는 쓸 수 없음. 답 검증과 출제 구조 파악용.

### 공통수학2 아이디어 지도 · 자료 있음

중단원별로 문제를 쉽게 풀게 해 주는 아이디어를 수준 표기와 함께 모은 페이지입니다. 원자료는 Claude와의 분석 대화에 있으며, 제작 전에 Claude가 이 문서에 정리해 올립니다. 예시 항목:

- 평면좌표: 무리식을 거리로 읽기, 신발끈 공식(교과외), 무게중심좌표(대학)
- 직선: 기울기 = tanθ, 반각·끼인각 공식, 닮음, 직선 다발, 부호로 영역 판정
- 원: 중심과 직선 거리 d와 r 비교, 등고선, 극선·방멱·근축(교과외), 아폴로니오스 원, 반전(대학)
- 이동: 역변환 대입 원리, 반사 원리와 최단거리, y=x+k 대칭 공식, 직선 대칭 일반 공식(대학)
- 집합: 원소별 독립 선택(3ⁿ 등), 벤 다이어그램 영역 미지수, 대칭차 = XOR, 특성함수·이진수(대학)
